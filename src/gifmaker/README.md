# Trincado GIF Maker

Aplicativo Android auxiliar para criar os assets animados próprios do Projeto Trincado no celular.

Fluxos suportados:
- importar uma colagem 2x2 e recortar automaticamente em quatro quadros;
- importar quadros separados;
- reordenar quadros e visualizar o loop ida/volta;
- gerar GIF local;
- compartilhar/salvar o GIF;
- guardar GIFs no IndexedDB do app;
- exportar um ZIP organizado por categoria/exercício com manifest.json.

O ZIP final segue o padrão:

```
core/elevacao-de-pernas/elevacao-de-pernas.gif
chest/supino-reto/supino-reto.gif
manifest.json
```
